# Codex Skills

This directory stores repository-visible mirrors of the global Codex skills used by this workflow.

These files do not replace the globally installed skills under `~/.codex/skills/`.
They exist so that:

- repository reviewers can inspect the default Codex operating rules
- new repositories created from this template inherit the same visible defaults
- project-local documentation and Codex global skills stay aligned

Default skills mirrored here:

- `gitea-flow.md`
- `evidence-publish.md`
- `team-msg.md`
- `gemini-advisor.md`
