# team-msg

Use this workflow for formal team notifications.

`msg` is a formal delivery and traceability layer, not a casual IM.

Use `msg` for:

- formal result publication
- review or confirmation requests
- task completion notifications
- daily/audit/report delivery

Prefer explicit recipients:

- `@user`
- `@team`

When formal evidence exists:

- prefer MinIO links over local paths
- publish evidence first
- then notify the right people
